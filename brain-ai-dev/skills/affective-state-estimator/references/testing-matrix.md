# Testing Matrix: Affective State Estimator

This document defines the concrete test specifications that must pass before the
Affective State Estimator is considered production-ready. Each category maps to a
test class generated by `scripts/gen_affect_tests.py`.

**Production config reference:** `hidden_dim=64`, `tau_mood=100`, all scales at 1.0.
Tests use minimal config (`hidden_dim=16`, `tau_mood=10`) for speed unless stated otherwise.

## 2. Valence-Arousal Space Tests

All tests use `B=4`.

### 2a) `test_neutral_point`

Zero inputs map to the neutral point `(0, 0, 0)` in PAD space.

```python
def test_neutral_point(space, device):
    v, a, d = space.from_signals(
        torch.zeros(4, device=device),  # rpe
        torch.zeros(4, device=device),  # uncertainty
        torch.zeros(4, device=device),  # pe_magnitude
        torch.zeros(4, device=device),  # novelty
        torch.zeros(4, device=device),  # homeostatic_dev
    )
    assert torch.allclose(v, torch.zeros(4, device=device), atol=1e-6)
    assert torch.allclose(a, torch.zeros(4, device=device), atol=1e-6)
    assert torch.allclose(d, torch.zeros(4, device=device), atol=1e-6)
```

### 2b) `test_bounded_outputs`

All outputs in `[-1, 1]` for extreme inputs.

### 2c) `test_circumplex_angle`

Positive RPE maps to circumplex angle near 0 (happy region).

### 2d) `test_pad_octants`

Specific signal combinations map to the correct PAD octant.

### 2e) `test_intensity_monotonic`

Larger signals produce higher affect intensity `sqrt(V^2 + A^2 + D^2)`.

### 2f) `test_deterministic`

Same inputs produce identical PAD outputs across two calls.

## 4. Affective Estimator Tests -- GATES (a) and (b)

All tests use `B=4`.

### 4a) `test_bounded_outputs_extreme` -- GATE (a) primary

**Gate (a) primary.** Feed extreme signals (magnitude 1e6); assert all affective
dimensions in `[-1, 1]` and all modulation factors positive.

```python
def test_bounded_outputs_extreme(estimator, device):
    """Gate (a): All outputs bounded even with extreme inputs."""
    signals = InternalSignals(
        reward_prediction_error=torch.full((4,), 1e6, device=device),
        epistemic_uncertainty=torch.full((4,), 1e6, device=device),
        prediction_error_magnitude=torch.full((4,), 1e6, device=device),
        novelty_score=torch.ones(4, device=device),
        homeostatic_deviation=torch.full((4,), 1e6, device=device),
    )
    state = estimator.estimate(signals)
    assert state.valence.abs().max() <= 1.0 + 1e-7
    assert state.arousal.abs().max() <= 1.0 + 1e-7
    assert state.dominance.abs().max() <= 1.0 + 1e-7
    mod = estimator.get_modulation(state)
    assert mod.lr_scale.min() > 0
    assert mod.attention_gain.min() > 0
    assert mod.exploration_temp.min() > 0
```

### 4b) `test_bounded_outputs_negative_extreme` -- GATE (a) secondary

Same as 4a but with large negative signals.

### 4c) `test_neutral_on_zero` -- GATE (b) primary

**Gate (b) primary.** Feed zero signals; assert neutral affect.


## 5. Affective Modulator Tests -- GATE (c)

All tests use `B=8`.

### 5a) `test_lr_increases_with_arousal` -- GATE (c) primary

**Gate (c) primary.** Higher absolute arousal produces higher learning rate scale.

```python
def test_lr_increases_with_arousal(modulator, device):
    """Gate (c): High arousal -> higher learning rate."""
    low_arousal_state = AffectiveState(
        valence=torch.zeros(8, device=device),
        arousal=torch.full((8,), 0.1, device=device),
        dominance=torch.zeros(8, device=device),
    )
    high_arousal_state = AffectiveState(
        valence=torch.zeros(8, device=device),
        arousal=torch.full((8,), 0.9, device=device),
        dominance=torch.zeros(8, device=device),
    )
    lr_low = modulator.modulate_learning_rate(0.001, low_arousal_state)
    lr_high = modulator.modulate_learning_rate(0.001, high_arousal_state)
    assert (lr_high > lr_low).all()
```

### 5b) `test_negative_valence_increases_risk`

Negative valence -> higher risk sensitivity.

### 5c) `test_low_dominance_increases_exploration`

Low dominance -> higher exploration temperature.

### 5d) `test_emotional_events_prioritized`

High arousal * |valence| -> higher memory priority.

### 5e) `test_strong_affect_sharpens_attention`

High |valence| * |arousal| -> higher attention gain.

### 5f) `test_modulation_positive`

All modulation factors are strictly positive for all inputs.

### 5g) `test_modulation_clamped`

All modulation factors within configured [floor, ceiling].

### 5h) `test_neutral_no_modulation`

Neutral affect (V=0, A=0, D=0) -> all modulation factors = 1.0.
