# Testing Matrix: Continual Learning Guard

Concrete test specifications for the continual learning guard. Each category maps to a test class generated by `scripts/gen_cl_tests.py`. Tests are in imperative form -- implement exactly as described.

**Target API:** Tests use the target API (`ewc_penalty`, `replay_sample`, `progressive_forward`, `detect_boundary`, `continual_step` returning `ContinualOutput`). Where the target API diverges from current code, the test describes intended behavior; bring the implementation into alignment before the test can pass.

**Test config:** Tests use small dimensions (`hidden_dim=32`, `input_dim=16`, `output_dim=5`) for speed unless stated otherwise.

## 2. TestEWCRegularizer (~10 tests)

EWC computes a diagonal Fisher information matrix and applies a quadratic penalty anchoring parameters near their task-optimal values.

All tests use `Linear(16, 32) -> ReLU -> Linear(32, 5)`.

---

### 2a) `test_fisher_diagonal_shape`

Compute Fisher diagonal on a toy dataset (20 samples). Assert each entry in the returned dict matches the shape of the corresponding model parameter.

### 2b) `test_fisher_diagonal_non_negative`

Compute Fisher diagonal. Assert all values are >= 0 (squared gradients cannot be negative).

### 2c) `test_fisher_computed_in_eval_mode`

Verify that `compute_fisher` sets model to `train(False)` during computation and restores the original mode afterward. Use a model with Dropout to confirm: Fisher should be deterministic (no dropout randomness) across two calls with the same data.

### 2d) `test_ewc_penalty_non_negative`

Compute EWC penalty for random current params vs stored star params. Assert penalty >= 0 (quadratic form with non-negative Fisher is PSD).

### 2e) `test_ewc_penalty_zero_at_optimum`

Set current params equal to star params. Assert EWC penalty is exactly 0.0.

### 2f) `test_ewc_penalty_increases_with_distance`

Compute penalty at distances d=0.1, d=0.5, d=1.0 from star params (uniform shift). Assert penalty is strictly monotonically increasing.

### 2g) `test_online_ewc_update`

Compute Fisher for task 1 and task 2 separately. Apply online update with gamma=0.5. Assert the online Fisher at each parameter equals 0.5 * F_1 + F_2 (within atol=1e-5).

### 2h) `test_online_ewc_bounds_memory`

Register 10 tasks with online EWC. Assert the total stored Fisher/params is O(|theta|), not O(10 * |theta|). Count the number of stored tensors.

### 2i) `test_fisher_normalization`

Enable normalize_fisher=True. After computation, assert max(F_diag) == 1.0 (within atol=1e-6).

### 2j) `test_ewc_gradient_flows`

Compute EWC penalty and call `.backward()`. Assert all model parameters that differ from star params have non-zero `.grad`.

## 3. TestSynapticIntelligence (~6 tests)

SI tracks parameter importance online during training via path integrals.

---

### 3a) `test_si_omega_shape`

After one task of training (10 steps), assert omega dict has entries matching all trainable parameter shapes.

### 3b) `test_si_omega_non_negative`

Assert all omega values are >= 0 (importance cannot be negative).

### 3c) `test_si_penalty_zero_at_optimum`

Set current params equal to star params. Assert SI penalty is exactly 0.0.

### 3d) `test_si_accumulates_during_training`

Run 20 training steps. Assert omega values after step 20 are greater than after step 5 (importance accumulates).

### 3e) `test_si_damping_prevents_division_by_zero`

Create a scenario where parameter change is zero (frozen parameter). Assert omega computation does not produce NaN or Inf thanks to the xi damping term.

### 3f) `test_si_gradient_flows`

Compute SI penalty and call `.backward()`. Assert all model parameters that differ from star params have non-zero `.grad`.

## 4. TestReplayBuffer (~10 tests)

Replay buffer stores exemplars from prior tasks with uniform or prioritized sampling.

---

### 4a) `test_reservoir_sampling_size`

Add 1000 items to a buffer of size 200. Assert `len(buffer) == 200`.

### 4b) `test_reservoir_sampling_uniform_coverage`

Add 5000 items (1000 from each of 5 classes) to a buffer of size 500. Count items per class. Assert each class has between 70 and 130 items (within statistical bounds for uniform sampling).

### 4c) `test_reservoir_sampling_probability`

Run 10000 trials of adding 100 items to a buffer of size 10. Track how often each item position is retained. Assert retention probability is approximately 10/100 = 0.1 for all positions (chi-squared test, p > 0.01).

### 4d) `test_priority_queue_ordering`

Add 10 items with priorities [1, 2, 3, ..., 10]. Sample 5 items 1000 times. Assert items with higher priority are sampled more frequently.

### 4e) `test_priority_update`

Add items with initial priorities. Update priorities for a subset. Sample and verify the updated priorities are reflected in sampling frequency.

### 4f) `test_replay_sample_shape`

Sample a batch of size 16 from a populated buffer. Assert x tensor has shape `(16, input_dim)` and y tensor has shape `(16,)`.

### 4g) `test_buffer_never_exceeds_max_size`

Add 10000 items to a buffer of size 100. At every 100 items, assert `len(buffer) <= 100`.

### 4h) `test_empty_buffer_raises`

Attempt to sample from an empty buffer. Assert ValueError is raised.

### 4i) `test_task_id_tracking`

Add items with task_id labels. Assert `buffer.task_ids()` returns all unique task IDs present in the buffer.

### 4j) `test_on_task_boundary`

Call `buffer.on_task_boundary(task_id=1)`. Assert the buffer state is updated (e.g., task count incremented, metadata recorded).

## 5. TestProgressiveNet (~8 tests)

Progressive network with lateral connections and column freezing.

---

### 5a) `test_single_column_forward`

Create a 1-column progressive net. Forward pass produces correct output shape `(B, output_dim)`.

### 5b) `test_add_column`

Add a second column. Assert `net.num_columns == 2` and the new column has lateral connections from column 1.

### 5c) `test_frozen_column_zero_gradient`

Freeze column 1. Run forward + backward on column 2. Assert all parameters in column 1 have `.grad` that is either None or all zeros.

### 5d) `test_lateral_connections_active`

Create a 2-column net. Forward pass on column 2. Verify lateral connections contribute to the output: compare output with and without lateral inputs; they should differ.

### 5e) `test_column_isolation`

Train column 2 for 10 steps. Assert column 1 parameters are unchanged (byte-for-byte identical to the snapshot taken before training).

### 5f) `test_max_columns_enforced`

Set max_columns=3. Add 3 columns successfully. Assert adding a 4th column raises ValueError.

### 5g) `test_forward_correct_task`

Create a 3-column net. Forward with task_id=2 uses column 2 (with laterals from columns 0 and 1). Verify by checking which column's head produces the output.

### 5h) `test_progressive_deterministic`

Fix seed. Two forward passes with identical input produce identical output.

## 6. TestPackNet (~6 tests)

PackNet prunes and freezes subnetworks for each task.

---

### 6a) `test_prune_creates_mask`

Train on task 1, prune with ratio 0.75. Assert a binary mask exists for task 1 with approximately 25% of weights set to 1.

### 6b) `test_masks_disjoint`

Train and prune tasks 1 and 2. Assert `(mask_1 AND mask_2).sum() == 0` for all parameter tensors.

### 6c) `test_frozen_weights_unchanged`

Freeze task 1's subnetwork. Train on task 2 for 20 steps. Assert task 1's frozen weights are unchanged.

### 6d) `test_capacity_decreases`

After each task, compute the fraction of free (unallocated) weights. Assert it decreases monotonically.

### 6e) `test_inference_with_mask`

Apply task 1's mask, run inference. Apply task 2's mask, run inference. Assert outputs differ (different subnetworks).

### 6f) `test_prune_ratio_respected`

Prune with ratio 0.75. Assert the number of pruned weights is within 5% of the expected 75%.

## 7. TestKnowledgeDistillation (~5 tests)

Knowledge distillation uses a frozen teacher to regularize the student.

---

### 7a) `test_distillation_loss_non_negative`

Compute distillation loss between teacher and student outputs. Assert loss >= 0.

### 7b) `test_distillation_loss_zero_identical`

Set student outputs equal to teacher outputs. Assert distillation loss is approximately 0.0 (within atol=1e-5).

### 7c) `test_teacher_frozen`

After creating teacher snapshot, train student for 10 steps. Assert teacher parameters are unchanged.

### 7d) `test_temperature_effect`

Compute distillation loss with T=1.0 and T=10.0. Assert T=10.0 produces smaller loss (softer targets are closer to uniform).

### 7e) `test_distillation_gradient_flows`

Compute distillation loss, call `.backward()`. Assert student parameters have non-zero `.grad`. Assert teacher parameters have no `.grad` (frozen).

## 8. TestTaskBoundary (~8 tests)

Task boundary detection using loss spikes, gradient norms, and distribution shift.

---

### 8a) `test_loss_spike_detection`

Feed 50 steps of loss ~1.0, then inject a spike of loss=5.0. Assert boundary is detected within 3 steps of the spike.

### 8b) `test_no_false_positive_stable`

Feed 200 steps of stable loss (noise with std=0.1 around mean 1.0). Assert no boundary is detected.

### 8c) `test_grad_norm_spike_detection`

Feed 50 steps of grad_norm ~1.0, then inject a spike of grad_norm=20.0. Assert boundary is detected.

### 8d) `test_manual_boundary`

Create a manual detector. Call `signal_boundary()`. Assert `boundary_detected` is True.

### 8e) `test_cooldown_prevents_rapid_fire`

Inject two spikes 5 steps apart. With cooldown=20, assert only one boundary is detected.

### 8f) `test_window_warmup`

Assert no boundary is detected during the first `window_size // 2` steps, even with noisy data.

### 8g) `test_detection_latency`

Inject a task switch at step 100. Measure the step at which the detector fires. Assert latency <= 10 steps.

### 8h) `test_reset_after_detection`

After a boundary is detected, assert the detector's internal statistics are reset (window cleared, ready for next task).

## 9. TestContinualLearner (~10 tests)

ContinualLearner orchestrates all CL methods for a multi-task training sequence.

---

### 9a) `test_continual_output_contract`

Run one step. Assert ContinualOutput has fields: `loss`, `task_loss`, `cl_penalty`, `metrics`, `boundary_detected`.

### 9b) `test_ewc_mode_adds_penalty`

Configure with EWC. Train task 1, register Fisher. Train task 2 for 1 step. Assert `cl_penalty > 0`.

### 9c) `test_replay_mode_mixes_data`

Configure with replay. Fill buffer from task 1. Train task 2. Assert replay samples appear in the training batch (check task_ids in batch).

### 9d) `test_progressive_mode_adds_column`

Configure with progressive. Start task 1 (1 column). Start task 2. Assert 2 columns exist.

### 9e) `test_multi_method_combination`

Configure with EWC + replay. Train 2-task sequence. Assert both EWC penalty and replay loss contribute to total loss.

### 9f) `test_forgetting_metric`

Train 3-task sequence. Compute forgetting metric. Assert it is a float in [-1, 1].

### 9g) `test_bwt_metric`

Train 3-task sequence. Compute backward transfer. Assert BWT is a float (negative = forgetting, positive = improvement).

### 9h) `test_avg_accuracy_metric`

Train 3-task sequence. Compute average accuracy. Assert it is a float in [0, 1].

### 9i) `test_no_cl_baseline`

Train 2-task sequence without any CL method. Assert Task-1 accuracy drops significantly after Task-2 training (establishes forgetting baseline).

### 9j) `test_ewc_vs_baseline`

Train 2-task sequence with and without EWC. Assert EWC achieves higher Task-1 retention than the baseline.

### 10d) `test_minimal_preset`

### 10e) `test_serialization_round_trip`

Create a config, serialize to dict, deserialize. Assert equality.

### 10f) `test_json_round_trip`

Save config to JSON, load from JSON. Assert equality.

### 10g) `test_clone_independence`

Clone a config, modify the clone. Assert original is unchanged.

### 10h) `test_cross_config_validation`

Create a config with EWC enabled but fisher_samples=0. Assert validate() raises or warns.

### Skip Conditions

| Decorator | Reason |
|---|---|
| `@pytest.mark.skipif(not torch.cuda.is_available(), reason="CUDA required")` | GPU-only tests |
| `@pytest.mark.skipif(not HAS_TORCHVISION, reason="torchvision required")` | Tests using real MNIST data |

### Marks

| Mark | Purpose |
|---|---|
| `@pytest.mark.slow` | Tests that take > 10 seconds (multi-task training sequences) |
| `@pytest.mark.gpu` | Tests requiring CUDA |
| `@pytest.mark.statistical` | Tests with probabilistic assertions (reservoir sampling) |

### Assertion Patterns

| Pattern | Code |
|---|---|
| Non-negative penalty | `assert penalty >= 0.0` |
| Zero at optimum | `assert abs(penalty) < 1e-8` |
| Gradient existence | `assert param.grad is not None and param.grad.abs().sum() > 0` |
| Frozen parameter | `assert param.grad is None or param.grad.abs().sum() == 0` |
| Buffer size bound | `assert len(buffer) <= max_size` |
| Monotonic increase | `assert all(a < b for a, b in zip(values, values[1:]))` |
| Statistical bound | `assert abs(observed - expected) < 3 * std / sqrt(n)` |
| Finite values | `assert torch.isfinite(tensor).all()` |
